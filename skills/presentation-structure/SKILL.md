# 汇报型 PPT 结构

## 流程
1. **一句话结论**：先写出这次汇报最想让听众记住的一句话，以及希望对方做出的决定或支持。
2. **选择叙事框架**（按场景选一个）：
   - 方案汇报：背景 → 问题 → 方案 → 收益与成本 → 风险 → 需要的决策；
   - 项目复盘：目标 → 结果 → 做得好的 → 问题与原因 → 改进计划；
   - 述职：业绩概览 → 关键成果（3 项）→ 能力成长 → 不足 → 下一阶段目标；
   - 数据汇报：核心结论 → 指标表现 → 结构拆解 → 原因分析 → 建议。
3. **逐页规划**：每页标题写成一句结论（例如"新客获取成本下降 18%，主要来自渠道 A"），正文 3–4 个要点支撑标题。
4. **控制规模**：10 分钟汇报约 8–10 页；首页标题、第二页放结论摘要，最后一页放决策 / 下一步。
5. 调用 ppt_plan 时把每页的结论标题和要点写进需求，再调用 ppt_generate；需要数据图表时先用 data_query 计算。

## 检查清单
- 只看各页标题，能否串成完整的故事？
- 每一页是否只讲一个观点？
- 数字是否都有来源？
