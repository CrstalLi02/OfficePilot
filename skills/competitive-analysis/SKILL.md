# 竞品分析

## 流程
1. **界定范围**：明确本方产品和 3–5 个竞品；用户没给竞品时，先用 web_search 找出主要竞品，并向用户说明筛选依据。
2. **确定对比维度**（按需要取舍）：定位与目标用户、核心功能、定价与商业模式、渠道与获客、技术与生态、近期动态（融资、发布、合作）。
3. **收集证据**：每个竞品至少检索官网和一条近期新闻；结论要能对应到来源，写明信息日期。查不到的标注"未公开"，不要猜测。
4. **输出**：
   - 对比表（sheet_generate 或文档内表格）；
   - 各竞品的优势 / 短板（每家 2–3 条，带依据）；
   - 差异化机会：找出竞品普遍做得弱、而用户确实在意的点；
   - 行动建议：按影响和成本排序，给出优先级。
5. 需要汇报时，把结论整理成 PPT（先 ppt_plan 再 ppt_generate），一页一个结论。

## 注意
- 区分"事实"（可查证）和"判断"（你的推断），判断要标明。
- 价格、功能会变化，文中注明检索日期。
